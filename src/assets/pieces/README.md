# Piece images

The "cburnett" chess pieces by Colin M.L. Burnett, from Wikimedia Commons
(e.g. https://commons.wikimedia.org/wiki/File:Chess_klt45.svg). They are
triple-licensed under the GFDL, BSD and GPL; this project uses them under the
BSD license.

The only changes are formatting: the XML prolog and DOCTYPE were removed, and
a `viewBox` was added so the images scale to fill a square.
